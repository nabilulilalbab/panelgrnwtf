🎯 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. SETTING QUOTA
   - Get current traffic from XRAY API
   - Save: username:quota_gb:initial_traffic:timestamp
   - Monitor from this baseline

2. MONITORING
   - Query current traffic via XRAY API
   - Calculate: used = current - initial
   - Compare with quota limit
   - If exceeded → disable user + notify

3. ENFORCEMENT
   - Comment user in XRAY config (#QUOTA_EXCEEDED_)
   - Restart XRAY service
   - Send Telegram notification
   - Log action

4. RESET
   - Remove #QUOTA_EXCEEDED_ prefix
   - Restart XRAY
   - Update baseline to current traffic
   - User can connect again
