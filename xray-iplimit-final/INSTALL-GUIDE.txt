🚀 QUICK INSTALL:
───────────────────────────────────────────────────────────────
1. Upload ke VPS:
   scp xray-iplimit-v5-package.tar.gz root@YOUR_VPS:/root/

2. SSH ke VPS:
   ssh root@YOUR_VPS
   cd /root
   tar -xzf xray-iplimit-v5-package.tar.gz
   cd xray-iplimit-final

3. Run installer:
   chmod +x install-xray-iplimit.sh
   ./install-xray-iplimit.sh

4. Set user limits:
   xray-iplimit set username 1 60
   # username: max 1 device (auto 3 IPs tolerance), lock 60 min
