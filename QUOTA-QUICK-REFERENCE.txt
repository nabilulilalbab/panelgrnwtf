COMMANDS:
─────────────────────────────────────────────────────────────
  xray-iplimit quota-set USER GB     Set quota (in GB)
  xray-iplimit quota-check USER      Check usage
  xray-iplimit quota-status          View all quotas
  xray-iplimit quota-monitor         Run monitoring
  xray-iplimit quota-reset USER      Reset quota

MENU OPTIONS:
─────────────────────────────────────────────────────────────
  [6] Set User Quota
  [7] Check User Quota
  [8] View All Quotas Status
  [9] Reset User Quota

FILES:
─────────────────────────────────────────────────────────────
  Config: /var/lib/xray-iplimit/user_quota.conf
  Log:    /var/log/xray/quota.log

EXAMPLES:
─────────────────────────────────────────────────────────────
  # Set 10 GB quota
  xray-iplimit quota-set john 10
  
  # Check usage
  xray-iplimit quota-check john
  
  # View all
  xray-iplimit quota-status
  
  # Reset
  xray-iplimit quota-reset john

CRON (Auto-Monitor):
─────────────────────────────────────────────────────────────
  */10 * * * * root /usr/bin/xray-iplimit quota-monitor
